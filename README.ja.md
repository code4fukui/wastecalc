# wastecalc
日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

廃棄物処理費用を見積もるための廃棄物計算機。

## デモ
電卓は https://code4fukui.github.io/wastecalc/ で利用できます。

## 機能
- 様々な廃棄物カテゴリーの廃棄処理費用を計算する
- 総費用と年間費用を提供する
- 徳島県上勝町の廃棄物処理料金に関する公開データを利用する

## 要件
特になし。このカリキュラムはブラウザ上で動作します。

## 使用方法
1. 各廃棄物カテゴリーの重量を入力してください。
2. 計算機はカテゴリーごとの推定コストと総コストを表示します。

## データ/API
このカウンターは、徳島県上勝町の廃棄物処理料金に関する公開データを使用しています。このデータは https://github.com/code4fukui/zerowaste/ で入手できます。
